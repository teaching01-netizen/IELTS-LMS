# Domain Docs

This repository uses a single-context layout.

Before exploring a task:

- Read `CONTEXT.md` at the repository root.
- Check `docs/adr/` for relevant decisions. It may be absent; do not create it solely for setup.
- Use the project's domain vocabulary in test names, plans, and reports.

The repository has no `CONTEXT-MAP.md`; there are no context-specific ADR directories currently configured.
