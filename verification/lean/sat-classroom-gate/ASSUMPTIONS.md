## Model assumptions

`Store.commit` atomically updates the room effect and `(actor, operationKey)` receipt. `Reachable` permits any request from any instance in any finite order; gate values remain fixed for each modeled process. Client `generic5xx` can be delivered whether the server committed or did not commit. The model starts with an empty, valid operation store. These assumptions are not evidence about a database, load balancer, browser, or deployment.
