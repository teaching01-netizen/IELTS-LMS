# Traceability: requirement → theorem → code → test

Status vocabulary: **Formal** (`PROVED` / `FAILED` / `NOT_RUN` / `INCOMPLETE`), **Correspondence**
(`MECHANIZED` / `REVIEWED_WITH_TESTS` / `UNVERIFIED` / `MISMATCH`), **Evidence**
(`VALIDATED_IN_STATED_PROFILE` / `PARTIAL` / `NOT_TESTED` / `FAILED`).

No row is `MECHANIZED`: the Lean model is hand-transcribed from the Go/TypeScript
source. `PROVED` is about the Lean statement only. The stated profile for
`VALIDATED_IN_STATED_PROFILE` is local MySQL 9.6.0 at its default isolation, one
host, `-race`. Production runs MySQL 8.4 (U-2), which was not run.
