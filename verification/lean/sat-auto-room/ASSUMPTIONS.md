`ready : Validator := True` exists only in the non-vacuity example with one synthetic payload. The universal safety theorems quantify over arbitrary validators; they do not prove the real Go validator sound. `new_release_validated` means that the supplied abstract validator accepted the payload. Imported releases can be arbitrary, so no theorem certifies every legacy release as validated.

Legacy receipts with NULL `response_snapshot` retain their original room identity where the live room exists. If it was deleted, recovery returns service-unavailable and preserves uncertainty. Exact original fields cannot be backfilled honestly. This is an explicit historical exception, not a verified exact-replay guarantee.
